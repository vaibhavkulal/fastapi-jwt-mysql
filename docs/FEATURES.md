# Features

This document is the high-level catalog of application capabilities.

## Authentication

- User registration
- Username/email login
- JWT access-token authentication
- Protected current-user endpoint

## Password Management

- Forgot-password flow
- Password reset flow
- Secure password hashing

## User Management

- User CRUD operations
- Role-based authorization
- Current-user/profile access

## Database

- MySQL persistence
- SQLAlchemy database access
- Alembic migrations

## Quality

- Automated tests
- Isolated test database

## Documentation Policy

Feature branches may introduce or modify capabilities. Pull Requests should describe the user-visible or developer-visible behavior being changed. The documentation workflow can update the feature catalog and changelog when documentation automation is enabled.
